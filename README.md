## 作品について

『大地の碑文』は、遺跡探索を題材にしたサスペンス・ノベルゲームです。

遺跡の調査中に発生する不可解な事件。  
怪異の存在を思わせる痕跡。  
探索が進むにつれ、その奥に隠された真相が少しずつ姿を現していきます。
